# 项目讲解与复盘提纲

## 60秒介绍

这个项目做的是A股多因子选股研究。我先用真实日线构建动量、反转、低波动、低换手四个因子，在每天的股票截面上截尾和标准化，用IC、Rank IC和分组收益检查因子表现。之后用过去约一年的成熟标签估计因子权重，在随后约三个月冻结权重，每月选取得分靠前的五只股票，并在下一交易日开盘调仓。

我重点处理了回测中的时序和资金问题：训练不能使用未来尚未走完的收益标签；买卖需要扣除成本；持仓会随价格变化，不能默认每天自动回到等权；涨跌停或停牌近似下的未成交订单也保留记录。最后把策略净值、回撤和两个指数放在同一期间比较，并输出逐笔成交、每日持仓和每个训练窗口的权重，方便检查。

第一版使用固定30只股票，是研究原型；没有历史全市场成分、ST与退市覆盖，因此我会明确说明样本偏差，不把结果说成可复制的实盘收益。具体收益数字以仓库当前报告为准。

## 面试官常见追问

|问题|需要讲清楚的内容|
|---|---|
|为什么需要多因子？|因子捕捉不同统计特征；不代表因子越多越好，相关性和稳定性需要另行验证。|
|为什么动量剔除最近20日？|将中期趋势与短期反转分开，是先验设计，未根据测试区间调参。|
|IC与Rank IC有什么区别？|前者比较数值的线性相关，后者比较排名相关，对极端值更稳健；都不能直接等同投资收益。|
|你说避免未来函数，具体怎么做？|t收盘信号在t+1开盘执行；训练只允许label_end不晚于训练截止；测试权重冻结，并有未来数据扰动测试。|
|滚动回测是每天重新训练吗？|本版每63个交易日训练一次，用过去252日，测试阶段冻结；窗口连续不清仓。|
|为什么训练末尾要剔除样本？|信号虽在训练期，但对应21日未来收益可能进入测试期，在当时还无法观察。|
|交易费用如何计入？|逐笔买卖金额乘成本率后从现金扣除；卖出先回笼现金，资金不够按比例买入。|
|收益不佳怎么办？|保留原始结果，分析因子方向、阶段稳定性、换手成本和样本偏差，不能根据这段测试表现反复改参后仍称样本外。|
|最大限制是什么？|固定样本及交易近似，缺乏历史股票池和ST/退市处理，分红基准口径也不同。|
