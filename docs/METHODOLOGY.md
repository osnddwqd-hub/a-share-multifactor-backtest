# 方法、时序与适用边界

## 1. 第一版目标

构建一条可以检查中间结果的量化研究链：日线数据 → 因子构建 → IC / Rank IC / 五分组检验 → 多因子打分 → 月度选股 → 连续滚动样本外回测 → 成本及风险指标。第一版没有实盘下单、机器学习择时或参数寻优。

默认股票池是 `configs/v1.json` 中30只人工固定的沪深主板股票。选择主板是为了使第一版交易限制近似保持一致。**它不是沪深300或中证500的历史成分股股票池，也不是无偏的全市场抽样。** 没有历史成分进出、历史ST名单、退市股票覆盖，因此存在人为选择与存活偏差；与指数比较只是参照。

## 2. 因子定义

记后复权收盘价为 P、每日换手率（百分数）为 Turn、收盘收益为 r。所有因子均在 t 日收盘后形成，值越大预设越优。

|因子|原始计算|预设假设|
|---|---|---|
|区间动量|P[t−20] / P[t−60] − 1|剔除最近20日，观察中期趋势延续|
|短期反转|−(P[t] / P[t−5] − 1)|近期跌幅较大的股票可能出现反转|
|低波动|−std(r[t−19:t]) × √252|低波动股票可能有相对优势|
|低换手|−mean(Turn[t−19:t])|低换手特征可能有相对优势|

这四项是待验证的研究假设，不能解释为收益保证。每个截面单独做1%/99%分位截尾，再用当日截面均值和总体标准差做Z-score；相同值变为0，缺失值保留缺失。至少具备120个交易日位置、最近61日都有真实报价且信号日成交量为正才能参与。该历史条数门槛不是完整上市天数筛选，也不能替代历史ST筛选。

## 3. 标签与检验

用于研究的21交易日标签为：`adj_open[t+22] / adj_open[t+1] − 1`，即 t 收盘形成信号，t+1开盘进入，t+22开盘退出。`label_end` 单独记录真正可观察该标签的日期。入场或出场没有真实报价/正成交量的标签会排除，避免用暂估价格形成假想可成交收益。

- IC：当日因子值与上述未来收益的Pearson相关。
- Rank IC：两者平均秩的Pearson相关，相当于Spearman。
- 五分组：按因子从低到高切为五组，各组等权的未来21日平均收益。相同因子值按股票代码稳定排序，不伪称存在经济排序差异。
- 分组图是**重叠标签的描述性均值**，不是五个可交易组合的累计净值；不含交易成本。
- 展示ICIR = Rank IC均值 / 标准差，**不年化**。相邻标签高度重叠，第一版不提供基于独立样本假设的t检验或“显著有效”宣称。
- `factor_ic_all.csv` 保留整个数据区间的研究检验；`factor_summary_oos.csv` 只总结回测期且标签已在数据截止日成熟的记录。这些完整样本外结果不参与过去的权重估计。

## 4. 滚动训练与冻结权重

默认每252日历史训练、随后63日测试，并向前滚动63日，测试窗口不重叠；仓位与现金连续衔接，窗口之间不虚拟清仓。训练窗口以该测试首日前一交易日为截止日，并只允许 `label_end <= train_cutoff` 的记录。**在训练末尾还没走完21日持有期的标签会被剔除。** 因子预热期位于首个训练窗口之前。

默认 `rolling_ic` 权重：计算训练期内各因子成熟标签的平均Rank IC，取非负部分后归一化。负均值因子权重为0，不根据测试表现翻转方向。若有效IC样本少于40个，或所有均值非正，则退回四因子等权。IC日样本数量不等于独立样本数量。也可以设 `weighting=equal` 作固定基线。

在63日测试窗口内冻结因子权重；每月第一个交易日，或新测试窗口首日，按前一交易日收盘因子计算加权总分，选择前5名目标等权。由于新窗口首日也换仓，默认不是“只有每月一次”的严格月频。`rebalance=weekly` 支持每周首个交易日。参数是预先固定的工程示例，没有按本次区间收益挑选。

示例：训练截止2023-12-29，则只能使用该日及之前已成熟标签；2024-01-02开盘执行2023-12-29收盘信号。不能用2024年的收益估计2024年首笔持仓。

## 5. 资金账本与成交近似

使用后复权价格下的**分数份额研究账本**：目标权重转换为复权单位，先卖后买；买入资金不足按比例缩小，绝不借款。每天用复权单位×收盘价＋现金估值，持仓权重随价格自然漂移，不进行隐含的每日等权再平衡。交易成本逐笔从现金扣除。

默认每侧手续费3 bp + 滑点5 bp，卖出再加5 bp税费；它们是2024—2025示例区间的固定研究假设，不是券商报价，也不是历史费率规则引擎。滑点表现为现金成本，不移动成交价。`price` / `adjusted_units` 不是可直接报给券商的真实股价和股数。初始资金100万元，不考虑现金利息，Sharpe无风险利率设0。

初始建仓在首个测试日开盘，所有比较序列从该开盘开始。后续策略收益包含持仓过夜收益与当日收益；两个指数从相同开盘基点持有，之后按收盘估值。期末按市值结束，**不假设清仓**，因此不计期末全部卖出的额外成本。总换手定义为买卖成交额之和 / 前日净资产，不再除以2。

停牌/交易限制采用保守近似：

- 成交量为0的明确行情条目禁止成交。
- 用原始收盘价及原始涨跌幅反推当日交易所参考前收盘价，再计算原始开盘涨幅，避免简单用昨天收盘价造成除权日误判。
- 开盘涨幅≥9.5%禁止买入；≤−9.5%禁止卖出。没有以全天最高/最低价等未来信息选择股票。成交日成交量仅用于识别整日无成交的非成交情形，不进入当日开盘选股打分。
- 未成交订单记录为BLOCKED；受现金约束的买单记录PARTIAL_CASH；仅在下一次计划调仓时重新计算目标，不每日自动追单。
- 卖不掉的旧股票继续持有，因此实际持仓数可能超过5；受阻、缺少候选、费用都会导致现金余额。

不覆盖20%/30%板块、历史ST限幅、精确涨跌停价与价格取整、盘中复牌、盘口队列与流动性冲击、单笔100股整手、最低5元佣金、除权除息现金流和全部上市退市事件。月/周频无日内往返，但不声称实现了完整交易所T+1规则引擎。

## 6. 数据与复现

来源为东方财富公开历史日线接口，`fqt=0` 原始行情用于限制近似，`fqt=2` 后复权开收盘用于因子与账本。换手率保留原始百分数尺度；横截面标准化后尺度不影响打分。行情供应方可能修订历史数据，后复权并不自动等于严格的point-in-time数据库。

下载明确与回测分离。默认必须有manifest，只有显式设置 `allow_unverified_data=true` 时才允许无来源验证的自有CSV。默认使用仓库CSV离线重跑，不会联网更新；SHA-256校验用于确认快照未变。接口异常会报错，绝不偷偷改用模拟数据。数据加载拒绝重复记录、非正或无穷价格、股票池不匹配以及缺失指数交易日。股票的区间端点缺失或连续缺报超过15日也会报错，防止掩盖上市/退市与源故障。少量区间内缺报不被冒称为已确认停牌：运行时显式标记 `observed=False`，按上次收盘价暂估持仓价值、成交量置0禁止成交，并在最近61日真实报价不完整时禁止该股票参加选股。报价恢复时累计价格变动才反映到持仓。每个缺报日期写入 `missing_quotes.csv`，原始CSV和哈希保持不变。本快照共有18条缺报，包含中国神华在2025年的连续10日缺报；数据加载可复现这些处理。此近似不替代停牌原因核验或完整退市处理，未知长时间缺报不能照此无限填充。

`data/manifest.json` 记录请求区间、来源、获取时刻、数据文件大小和哈希。固定股票池不能凭一次历史行情下载消除样本偏差；也不宣称财务因子的公告日对齐，因为本版没有使用财务因子。

## 7. 指标口径

采用252交易日年化；累计收益为净值末值/初值−1，年化为累计财富的252/N次方−1；年化波动为日收益总体标准差×√252；Sharpe为日收益均值×252/年化波动；Calmar为年化收益/最大回撤绝对值。零波动或零回撤导致分母为0时输出null。最大回撤包含初始财富1，首日交易成本也计入回撤。

报告另外提供相对指数的终值财富比−1、日主动收益信息比率、分窗口收益与费用。后复权股票账本与**价格指数**在分红口径上不完全一致；第一版不将相对收益命名为纯选股alpha。

## 8. 关键代码验证

测试覆盖：截断未来数据时因子不变；下一开盘与标签成熟日对齐；训练剔除未成熟标签；未来价格被大幅改写时过去成交与净值不变；手算买卖成本、资金守恒；涨跌停代理与停牌不成交；首日损失计入回撤；平价反复换仓因成本损失。

测试中的确定性模拟数据仅用于验证公式与时序；公开回测结果来自 `data/` 中的真实行情快照。
